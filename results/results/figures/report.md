# Qiskit Knapsack Optimization Project Report

## 1. Objective
This project explores the 0-1 knapsack optimization problem and prepares a framework for comparing quantum processor connectivity.

## 2. Problem Description
The goal is to select items with the highest total value while keeping their total weight within a specified capacity.

## 3. Validation
A toy knapsack example was tested, producing a total value of 9. Further testing is required to confirm the result against all problem constraints.

## 4. Processor Comparison
The project includes utilities for representing processor connectivity, checking graph connectivity, and calculating basic connectivity metrics.

## 5. Results
Final results and figures will be added after the implementation has been tested.

## 6. Limitations
The current code is a preliminary implementation. Processor specifications, routing behavior, and experimental results must be validated against the hackathon requirements.

## 7. Conclusion
The project establishes an initial framework for knapsack validation and processor-connectivity analysis.
